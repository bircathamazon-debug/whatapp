# Logo / imagen original

`logo-original.webp` es la imagen que eligió el usuario para el ícono de la
app (la que se usó para generar `app/assets/icon.png` y los archivos de
`app/public/`). Se guarda acá en calidad original por si hace falta volver
a generar íconos en otro tamaño o estilo más adelante.

## Idea anotada para el futuro
El usuario mencionó la posibilidad de copiar este sistema (bot +
app + motor de reservas) para una estilista de uñas, como negocio
separado — todavía sin arrancar, va a pasar otra foto/logo para esa
versión cuando se retome.
